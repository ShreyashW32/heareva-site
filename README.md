# heareva.com

The website for Eva, an AI phone agent for Australian trade businesses. It's a static site with no build step and no server code.

- `index.html`: the main page
- `privacy.html`: the privacy page
- `assets/`: logos, share image and fonts
- `audio/`: voice clips reading made-up example calls

To preview it, open `index.html` in a browser.

The fonts, Instrument Sans and Instrument Serif, are under the SIL Open Font License. Copies of the licence are in `assets/fonts/`.
